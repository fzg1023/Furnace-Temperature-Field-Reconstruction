This document primarily concerns the reconstruction iterations of the Hybrid RBF‑PR‑TWSVD method, accounting for refraction effects, for two furnace configurations: a 24m × 24m boiler structure with a bimodal skewed temperature field, and a 32m × 24m boiler structure with a unimodal skewed temperature field. The data for these two boiler structures are stored separately in two folders, namely Bimodal skewed temperature field_24&24 and Unimodal skewed temperature field_32&24. Each folder contains five script files and one data file.

1.The file pathT1 serves as the fundamental data file. Its functions include sensor placement, path creation, generation of ideal data, and the addition of errors, etc. The data ultimately generated by this file are supplied to subsequent programs for temperature field reconstruction.
☆☆☆NOTE: Each execution of pathT1 randomly generates a completely different set of fundamental data. To reproduce the temperature field reconstruction results presented in the paper, it is permissible to skip the execution of this file and directly run the subsequent temperature field reconstruction programs.

2.The file TemperatureReconstructionData stores the data finally generated by the fundamental data program pathT1.

3.The file Experiment_ShootRK4 contains the reconstruction code for the Hybrid RBF‑PR‑TWSVD method that accounts for refraction effects; its original data are sourced from pathT1.

4.buildHybridRBFDesign and buildRBFDesign are programs for constructing radial basis function (RBF) design matrices.

5.solveSVD_RBF is the program implementing the SVD‑based solution method for the RBF approach.
